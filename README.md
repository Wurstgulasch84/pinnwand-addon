# Pinnwand für Home Assistant

Home-Assistant-Add-on für die eigene digitale Pinnwand. Der Programmcode der Pinnwand liegt in einem eigenen, privaten Repository und wird beim Start mit einem Lese-Schlüssel geholt.

Einrichtung: in Home Assistant unter Einstellungen › Add-ons › Add-on-Store › ⋮ › Repositories diese Adresse hinzufügen:

    https://github.com/Wurstgulasch84/pinnwand-addon

Details stehen in `pinnwand/DOCS.md`.
